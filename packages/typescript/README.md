# @mapseek/raster-style

TypeScript / 浏览器 / Node.js 的 Raster Style Spec v2 Q2 编解码工具。公共入口导出 `encodeQuery`、`decodeQuery`、`jsonToQuery`、`queryToJson`、`QueryCodec`、`RasterStyle` 和结构化错误类型。

使用方法见[项目说明](https://github.com/mapseekai/raster-style/blob/main/README.md)和 [SDK 接口](https://github.com/mapseekai/raster-style/blob/main/docs/SDK.md)。协议版本为 `2.0`，SDK 版本为 `0.2.0`。

## 安装

```sh
npm install @mapseek/raster-style@0.2.0
```
