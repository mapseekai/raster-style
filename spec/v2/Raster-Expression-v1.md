# raster-expr/1

本文件是 Raster Style v2 的规范性表达式档案。表达式只读取服务绑定的波段，不访问对象、文件、网络或宿主语言。SDK 负责长度、输出数量及传输；服务负责下面的完整语法、类型和绑定校验。

## 1. 词法与语法

标识符区分大小写。波段为 `b[1-9][0-9]*`，编号 1–65535，不接受前导零。无符号数词法为 `(?:0|[1-9][0-9]*)(?:\.[0-9]+)?(?:[eE][+-]?[0-9]+)?`，解析结果必须为有限 binary64。正负号属于一元运算。空白仅 SP、HT、CR、LF，可出现在 token 之间。多个输出用分号分隔，最多三个；renderer 决定实际数量。

```ebnf
outputs    = expr, { ";", expr } ;
expr       = product, { ("+" | "-"), product } ;
product    = unary, { ("*" | "/"), unary } ;
unary      = ("+" | "-"), unary | atom ;
atom       = number | band | "(", expr, ")" | call | selection ;
call       = function, "(", expr, { ",", expr }, ")" ;
selection  = "where", "(", condition, ",", expr, ",", expr, ")" ;
condition  = expr, comparator, expr | "(", condition, ")" ;
comparator = "<" | "<=" | ">" | ">=" | "==" | "!=" ;
function   = "abs" | "min" | "max" | "clamp" | "sqrt" | "log" | "exp" | "pow" ;
```

括号最高，其次一元正负号，其次乘除，最后加减。同级二元运算从左到右。比较只产生 where 条件；不允许比较链、隐式数值转布尔、布尔算术、逻辑运算符或隐式乘法。函数参数数量按下表检查。

## 2. 函数

| 函数 | 语义与有效范围 |
|---|---|
| abs(x) | 绝对值 |
| min(a,b) / max(a,b) | 两个数的最小值 / 最大值 |
| clamp(x,lo,hi) | min(max(x,lo),hi)；lo ≤ hi |
| sqrt(x) | 非负平方根；x ≥ 0 |
| log(x) | 自然对数；x > 0 |
| exp(x) | 自然指数 |
| pow(x,y) | 实数幂；负底数要求 y 为可表示的整数；0 的负次幂无效，0^0=1 |
| where(condition,a,b) | 条件为真时取 a，否则取 b |

基本运算按 binary64 求值；任一实际求值的数值节点产生非有限结果、除以 ±0 或违反函数定义域，则该节点无效。有限下溢到 0 保持有效。±0 比较相等。比较直接使用数值相等／大小关系，不使用 epsilon；无效操作数产生无效条件。所有普通函数和运算要求其操作数有效。

where 先求条件，只传播被选择分支的数值与有效性。条件无效时输出无效；未选择分支的除零、定义域错误或波段掩膜不影响该像元。实现可向量化，但须保持此规则。整个 AST（包括未选分支）仍须通过函数、类型和波段绑定校验。

示例：

| 表达式与输入 | 输出 |
|---|---|
| `1+2*3` | 有效 7 |
| `8/2/2` | 有效 2 |
| `where(b1 != 0, 1/b1, 0)`，b1=0 且有效 | 有效 0 |
| `where(b1 > 0, b2, b3)`，b1=1、b2=5 有效，b3 无效 | 有效 5 |
| `where(b1 > 0, 1, 0)`，b1 无效 | 无效 |
| `sqrt(-1)` / `log(0)` / `1/0` | 无效 |

## 3. 绑定和执行边界

服务编译一次 AST，收集所有输出和所有分支引用的波段，去重并按波段号升序建立依赖表。索引输入从 bindings 的值建立同样的表；bidx 输入也按该规则建立表，输出仍保留 bidx 的原始顺序及重复项。before_channels 的 rank_channel 指该表的位置，服务必须在执行前校验其存在。

每个输出分别携带有效性；RGB 在三个输出的有效性上求交。未使用的源波段不参与判断。before_channels 镶嵌选择完整依赖元组，其有效性先按执行语义定义，再运行表达式；where 的分支规则不恢复已经被该镶嵌步骤丢弃的元组。

服务为 AST 深度、节点数、输入依赖数量和执行成本设置部署预算，超限须明确拒绝，不改写运算或静默丢弃输出。表达式内部文本由 SDK 保留；编译器不得使用宿主语言 eval。
